神经网络：一层一层算出来

逻辑回归只算一次加权和，再压成一个概率。神经网络先用几组权重各算一个加权和，每个结果过一道弯折，再把这几个数当成新的特征交给下一层。这份笔记用一个 21 个参数的小网络，把一次预测和一次学习里的每个乘法、加法都写出来；再看 401 个参数的网络在 2000 条数据上学到了什么，又多学了什么。

样本 2462 的输入3 个数
→
隐藏层4 个数
→
点开的概率0.3136
→
学一步之后0.3382

数据是一个固定种子的脚本生成的示意数据：音乐 App 首页推荐，一次曝光是给一位用户展示一首歌，点开并播放超过 30 秒算正样本（label = 1），没点、划走或不到 30 秒算负样本。3000 次曝光按天切成训练（第 1–20 天，2000 条）、验证（第 21–24 天，400 条）、测试（第 25–30 天，600 条）三段。页面里的权重、中间结果和指标都是用这个脚本在这份数据上算的，配方写在用到它的地方。这一页展开的是总览里神经网络、前向传播和反向传播三站。

01一个加权和画不出的规律

逻辑回归（梯度下降那一页训练的模型）给每个特征一个权重，加起来再过 sigmoid 变成概率。每个特征的作用是固定的：晚上曝光加多少分，不管歌长还是短都一样。数据里偏偏有一条规律不是这样。把 3000 次曝光按"是不是晚上"和"是不是长歌"分成四格，看正样本的比例：

短歌（不到 4 分钟）长歌（4 分钟及以上）
白天0.3469（784 次）0.1200（825 次）
晚上0.1200（675 次）0.3156（716 次）

晚上指 18 点到次日 2 点之前。

白天爱听短歌，晚上爱听长歌。"晚上"本身不加分也不减分，要看和歌的长短配不配。

一个加权和排不出这四格。设分数 z = c + a × 晚上 + b × 长歌（晚上、长歌取 0 或 1）：

白天短歌   c            要高
白天长歌   c + b        要低
晚上短歌   c + a        要低
晚上长歌   c + a + b    要高

两格"要高"加起来是 2c + a + b，两格"要低"加起来也是 2c + a + b，前者不可能比后者大，所以 a、b、c 取什么都排不出这个顺序。sigmoid 只是把分数单调地压到 0 到 1，不改变大小顺序。

训练出来也是这样。15 个特征的逻辑回归给"晚上"的权重是 −0.0631，给歌长的是 −0.1642；它在测试集上对四格的平均预测是 0.2575、0.2255、0.2154、0.2045，几乎是平的，按真实规律应该是 0.331、0.1203、0.1133、0.3419。有两条路：

  • 人来造特征。加一个交叉特征：晚上和长歌相同（同为 1 或同为 0）时取 1。它学到的权重是 0.7208，测试集 AUC 从 0.7175 升到 0.7715（AUC 见评估）。前提是你已经知道该交叉这两个。
  • 让模型自己造。先用几组权重各算一个加权和，各自弯一下，再把结果加权求和。这就是神经网络。

二维演示把这件事放大了。200 个点，横轴是曝光时间 6–24 点，纵轴是歌曲时长 2–6 分钟，白天短歌和晚上长歌点开的概率是 0.88，其余是 0.12。逻辑回归在这 200 个点上的准确率是 0.535，全猜"不点"也有 0.52；2→6→1 的网络（2 个输入、6 个隐藏单元、1 个输出）是 0.89，照着真实规则猜也只能对 0.90。总览第 5 站用的就是这 200 个点。

02神经元、层和网络

神经网络里最小的计算单位叫神经元，也叫单元（unit）。它做两件事：

z = w1·x1 + w2·x2 + … + b      加权和，和逻辑回归一样
a = f(z)                       过一个激活函数 f

w 是权重，b 是偏置，f 是一个固定的函数（下一节）。f 取 sigmoid 时，一个神经元就是一个逻辑回归。

几个神经元看同一份输入、各用各的权重，就是一层。第 04 节小网络的第一层有 4 个神经元，每个看 3 个输入：4 组权重排成 4 行 3 列的矩阵 W，4 个偏置排成向量 b，整层一次写完：

z = W·x + b      (4×3)·(3) + (4) = (4)
h = f(z)         对 4 个数逐个算

一层的输出是下一层的输入，几层串起来就是网络。3→4→1 表示 3 个输入、一个 4 个单元的中间层、1 个输出。中间这层叫隐藏层：数据里没有它该收什么、该出什么，它算什么全由训练决定。每个单元都连着上一层的全部输出，这种层叫全连接层。隐藏层多于一层的网络常叫深度神经网络（DNN）。

参数这样数：每层的权重是"输入数 × 单元数"，偏置是"单元数"。3→4→1 是 3×4 + 4 + 4×1 + 1 = 21 个；第 09 节的 15→16→8→1 是 15×16 + 16 + 16×8 + 8 + 8×1 + 1 = 401 个；15 个特征的逻辑回归是 16 个。写成代码，一层就是两重循环：外层遍历单元，内层遍历输入做乘加，Kotlin 版见第 14 节。

03激活函数：为什么要弯一下

先看不弯会怎样。两层都只做加权和：

第 1 层   h = 2x + 1
第 2 层   y = 3h - 4
合起来    y = 3(2x + 1) - 4 = 6x - 1

两层 4 个数，等于一层 2 个数。换成矩阵也一样：W2(W1x + b1) + b2 = (W2W1)x + (W2b1 + b2)，还是一个加权和。叠多少层都能合成一层，第 01 节那四格照样排不出来。

在两层中间加一个 ReLU，也就是把小于 0 的数变成 0：

y = 3·max(0, 2x + 1) - 4

x = -1    h = max(0, -1) = 0    y = -4
x =  0    h = max(0,  1) = 1    y = -1
x =  1    h = max(0,  3) = 3    y =  5

x 小于 −0.5 时输出一直是 −4，大于 −0.5 时是 6x − 1，在 −0.5 处拐了一个弯（不弯的版本在 x = −1 时是 −7）。一个单元拐一个弯，几个单元的弯加在一起，就能拼出折线、凹槽、四格这样的形状。这个弯叫非线性，加在加权和后面提供它的函数叫激活函数。常用的三个：

名字公式输出范围斜率（导数）用在哪
sigmoid1 / (1 + e−z)0 到 1p(1 − p)，最大 0.25输出层，把分数变成概率
tanh(ez − e−z) / (ez + e−z)−1 到 11 − h²，最大 1隐藏层；第 08 节的二维演示
ReLUmax(0, z)0 到无穷z > 0 时 1，否则 0现在的隐藏层最常用

z = 2 时三者分别是 0.8808、0.9640、2；z = −2 时是 0.1192、−0.9640、0。斜率那一列训练时要用：误差往回传，每经过一个单元都要乘一次它的斜率（第 06、12 节）。输出层要一个概率时用 sigmoid；要在几个类别里选一个时用 softmax，它把几个分数变成加起来等于 1 的几个概率。

04前向传播：样本 2462 走一遍

从输入一层层算到输出，叫前向传播，预测就是做一次前向传播。用一个最小的网络来算：

  • 输入 3 个特征：曲风偏好 affinity ÷ 30（用户最近 7 天听这个曲风的次数，最多 30）、歌曲热度 heat、是否关注了歌手 follow。都在 0 到 1 之间，没做标准化。
  • 结构 3→4→1：4 个 ReLU 单元，1 个 sigmoid 输出，21 个参数。
  • 训练：2000 条训练样本，He 初始化（第 11 节，种子 7），逐个样本的随机梯度下降，学习率 0.05，60 轮。训练完权重四舍五入到两位小数，下面的数都用两位小数的权重算。它的测试 AUC 是 0.7191，同样 3 个特征的逻辑回归是 0.7234。
W1                       b1
 2.15  -0.78  -1.14      0.05      单元 1
 0.71  -0.42   1.30     -0.34      单元 2
-0.59  -0.99  -1.25      0         单元 3
 3.21   1.30   0.39      0.01      单元 4

W2   0.33   0.59   1.38   0.89     b2   -1.81

样本 2462 来自测试集（第 25 天）：用户 60 晚上 20 点刷到歌曲 137，一首 5.4 分钟的民谣。他这个曲风最近 7 天听了 6 次，歌的热度 0.32，没关注歌手。这次他点开听了 30 秒以上，label = 1。网络只看三个数：x = [6 ÷ 30, 0.32, 0] = [0.2, 0.32, 0]。

第一层：4 个加权和

z1 =  2.15×0.2 + (-0.78)×0.32 + (-1.14)×0 + 0.05  =  0.43  - 0.2496 + 0 + 0.05 =  0.2304
z2 =  0.71×0.2 + (-0.42)×0.32 +   1.30×0  - 0.34  =  0.142 - 0.1344 + 0 - 0.34 = -0.3324
z3 = -0.59×0.2 + (-0.99)×0.32 + (-1.25)×0 + 0     = -0.118 - 0.3168 + 0 + 0    = -0.4348
z4 =  3.21×0.2 +   1.30×0.32  +   0.39×0  + 0.01  =  0.642 + 0.416  + 0 + 0.01 =  1.068

ReLU

h = [max(0, 0.2304), max(0, -0.3324), max(0, -0.4348), max(0, 1.068)]
  = [0.2304, 0, 0, 1.068]

第二层：1 个加权和，再过 sigmoid

z = 0.33×0.2304 + 0.59×0 + 1.38×0 + 0.89×1.068 - 1.81
  = 0.076032 + 0 + 0 + 0.95052 - 1.81
  = -0.7834

p = 1 / (1 + e^0.7834) = 1 / (1 + 2.1889) = 0.3136

网络说这次点开的概率是 0.3136。一共做了 16 次乘法、16 次加法（含加偏置）、4 次 ReLU、1 次指数。乘加的次数等于权重的个数，每个权重用一次；401 个参数的网络做一次预测是 376 次乘加。

把 ReLU 拿掉，两层就能合成一层：W2·W1 = [3.1711, −0.7144, −0.9871]，W2·b1 + b2 = −1.9852，z = 3.1711·x1 − 0.7144·x2 − 0.9871·x3 − 1.9852。样本 2462 代进去得 −1.5796，一层一层算也是 −1.5796。21 个数退化成 4 个数，就是一个逻辑回归。

这个样本按真实规律算的概率是 0.5226，网络只给了 0.3136。差的那部分它看不到：生成数据的规则里，"晚上 + 长歌"加 0.8 分，"晚上听民谣"再加 0.4 分，而这三个输入里既没有时间也没有歌长。模型能做到多好，先由给它的特征决定，见特征和样本。

05第 3 个单元为什么一直是 0

单元 3 的三个权重 −0.59、−0.99、−1.25 都是负的，偏置是 0。三个输入都不小于 0，它的加权和就不会大于 0，过了 ReLU 永远是 0。单元的输出大于 0 叫激活。在 2000 条训练样本上数一数每个单元的激活比例：

单元权重偏置激活比例什么时候激活
12.15, −0.78, −1.140.0537.4%没关注歌手，并且 2.15 × 偏好 > 0.78 × 热度 − 0.05；关注了的只有 0.3%
20.71, −0.42, 1.30−0.3411.9%关注了歌手的样本 100% 激活，没关注的只有 0.04%
3−0.59, −0.99, −1.2500从不激活
43.21, 1.30, 0.390.01100%一直激活。权重全是正的，等于一个不弯的加权和

真正在拐弯的只有 1 和 2，一个管没关注歌手的，一个管关注了的；4 是直的，3 是死的。

单元 3 一直是 0，就一直学不到东西。反向传播时误差要乘 ReLU 的斜率（第 06 节），加权和不大于 0 时斜率是 0，传到它这里就成了 0；它连到输出的权重，梯度是"误差 × 它的输出"，也是 0。对一下初始值就能确认：种子 7 给它抽的初始权重是 −0.5950、−0.9934、−1.2486，偏置 0，连到输出的权重 1.3763；训练 60 轮后，这 5 个数和初始值一模一样。输出层里最大的权重 1.38 不是学出来的，是初始化时抽到的，从来没被用上。

这叫死掉的 ReLU（dead ReLU）：对所有输入都输出 0，也就再也收不到梯度。这一个是一开始就死的：输入全是正数，三个权重随机抽正负，全抽到负的机会是 1/8，偏置又从 0 开始。学习率太大、一步把偏置推得很负，也会让单元死掉。避免的办法：

  • 输入做标准化（减去均值、除以标准差），让每个特征有正有负。第 09 节的网络用的是标准化后的特征，训练完 24 个隐藏单元没有一个是死的。
  • 换成 Leaky ReLU：z 小于 0 时不给 0，给一个很小的斜率，比如 0.01z，梯度总能传过去一点。
  • 学习率别太大，训练时统计每个单元的激活比例，长期为 0 的就是死了。

06反向传播：一个样本学一步

学习要回答：21 个参数各往哪边改、改多少，预测才会更准。答案是每个参数的梯度，也就是"这个参数加一点点，损失跟着变多少"。有了梯度，按梯度下降往反方向走一步。反向传播是一次把 21 个梯度全算出来的办法：从输出往回，一层一层算。

损失

用对数损失（log loss）：label = 1 时损失是 −ln p，label = 0 时是 −ln(1 − p)，p 越接近正确答案，损失越接近 0。下面的中间结果都用不取整的数算，显示时保留 4 位小数，拿显示的数重算，末位可能差 1。样本 2462 是正样本：

L = -ln 0.3136 = 1.1597

第 1 步：输出的误差 δ

先算损失对输出层加权和 z 的导数，记作 δ（delta），这一页叫它误差。sigmoid 配对数损失时，它化简后正好是 p − y（y 是标签，这里是 1）：

dL/dp = -1/p     = -3.189
dp/dz = p(1 - p) =  0.2152
δ = dL/dz = (-1/p) × p(1 - p) = -(1 - p) = p - y = 0.3136 - 1 = -0.6864

δ 是负的，意思是 z 应该变大。

第 2 步：输出层的梯度

z = w2·h + b2，所以 w2 每个数的梯度是 δ 乘上它连着的那个 h，b2 的梯度就是 δ：

dL/dw2 = δ × h = -0.6864 × [0.2304, 0, 0, 1.068] = [-0.1582, 0, 0, -0.7331]
dL/db2 = δ     = -0.6864

第 3 步：误差传回隐藏层

每个隐藏单元分到的误差，等于它连到输出的权重 × δ × ReLU 在它这里的斜率：

δ1 = 0.33 × (-0.6864) × 1 = -0.2265
δ2 = 0.59 × (-0.6864) × 0 =  0
δ3 = 1.38 × (-0.6864) × 0 =  0
δ4 = 0.89 × (-0.6864) × 1 = -0.6109

第 4 步：第一层的梯度

W1 里连着单元 j 和输入 k 的权重，梯度是 δj × xk；单元 j 的偏置，梯度是 δj：

连 x1 = 0.2连 x2 = 0.32连 x3 = 0偏置
单元 1（δ = −0.2265）−0.0453−0.07250−0.2265
单元 2、3（δ = 0）0000
单元 4（δ = −0.6109）−0.1222−0.19550−0.6109

21 个梯度里只有 9 个不是 0：被 ReLU 关掉的单元 2、3 不改，连着 x3 = 0 的权重也不改。可以用笨办法核对：把 w2 的第 4 个数 0.89 加上 0.000001，重新前向一遍，损失减少 0.000000733，比值 −0.7331，和上面一样。这叫数值梯度检查，自己写反向传播时常用它查错。

走一步

每个参数减去"学习率 × 梯度"。学习率用训练这个网络时的 0.05，W1[1] 指 W1 里单元 1 那一行：

w2      0.33 -> 0.33 + 0.05×0.1582 = 0.3379       0.89 -> 0.9267
b2     -1.81 -> -1.81 + 0.05×0.6864 = -1.7757
W1[1]   2.15 -> 2.1523    -0.78 -> -0.7764    b1[1]  0.05 -> 0.0613
W1[4]   3.21 -> 3.2161     1.30 -> 1.3098     b1[4]  0.01 -> 0.0405

用新参数再前向一遍：z1 = 0.2433，z4 = 1.1029，输出的 z = −0.6714，p = 0.3382，这个样本的损失从 1.1597 降到 1.0842。步子多大由学习率决定：同样的梯度，学习率取 0.01、0.1、0.5、1，这一步之后 p 分别是 0.3184、0.3643、0.6132、0.8788。

这一步只照顾了一个样本。它把训练集里每个样本的概率都推高了一点，平均从 0.2853 到 0.3052。负样本的损失跟着升，而负样本占 77%，训练集的平均损失反而从 0.5161 升到 0.5233。所以训练要轮流看所有样本，每步只改一点，下一个负样本会把多推的拉回来。这个小网络训练 60 轮，一共走了 120000 步。

07链式法则：多少层都一样

上一节只用了一条规则：几个函数套在一起，总的导数等于每一层的导数相乘，这叫链式法则。拿 W1 左上角的权重 2.15 来看，它影响损失的路径是 w → z1 → h1 → z → p → L，每一段的导数只和这一段有关：

dL/dp    = -1/p      = -3.189
dp/dz    = p(1 - p)  =  0.2152
dz/dh1   = w2[1]     =  0.33      单元 1 连到输出的权重
dh1/dz1  = ReLU'     =  1         z1 > 0，斜率是 1
dz1/dw   = x1        =  0.2
相乘：-3.189 × 0.2152 × 0.33 × 1 × 0.2 = -0.0453

和上一节表里的 −0.0453 一样。反向传播就是按这个顺序从后往前乘，共用的部分只算一次：前四项的乘积就是 δ1，单元 1 的 3 个权重和 1 个偏置都用它。换成任意多层（l 是层号），每一层做同样的三件事：

δ[l]     = (W[l+1]ᵀ · δ[l+1]) ⊙ f'(z[l])     误差收回来，再乘斜率
dL/dW[l] = δ[l] · a[l-1]ᵀ                    梯度 = 误差 × 这条边的输入
dL/db[l] = δ[l]

Wᵀ 是 W 的转置：前向时一个单元把输出分给下一层的很多单元，反向时它按同样的权重把这些单元的误差收回来。⊙ 是两个向量逐个相乘，f′ 是激活函数的斜率，a[l−1] 是上一层的输出。

  • 先前向，再反向。反向要用前向时每层的 z 和输出，训练时这些中间结果都得留在内存里。
  • 反向的计算量大约是前向的两倍：每层算一次传回去的误差，再算一次权重的梯度。这个小网络前向 16 次乘法，反向 20 次（传回误差 4 次，两层的梯度 4 + 12 次）。
  • 不用自己写。PyTorch、TensorFlow 这类框架在前向时记下每个运算，调一次反向就算出所有梯度，这叫自动求导。生成这一页数据的脚本是手写的，反向传播只有十来行。
  • 每过一层都要乘一次斜率，层数一多，这串乘积可能越乘越小，见第 12 节。

08隐藏单元学到了什么

回到第 01 节的二维演示，看 2→6→1 的网络怎么排出四格。配方：200 个点的两个坐标各自线性缩放到 [−1, 1]；6 个 tanh 隐藏单元，1 个 sigmoid 输出；初始权重按 He 的方式抽（种子 3）；逐个样本的随机梯度下降，学习率 0.05，300 轮。

一个 tanh 单元算的是 tanh(w1·时间 + w2·时长 + b)。加权和等于 0 的点在平面上连成一条直线，线的一侧输出接近 +1，另一侧接近 −1，权重越大过渡越陡。所以每个隐藏单元做的事，是画一条线，回答"这个点在线的哪一边"。

6 条线没有一条正好落在 18 点或 4 分钟上。网络不知道规则长什么样，它找到的是一组斜线，合起来能把这 200 个点分开，准确率 0.89。输出层怎么合，看四个象限中心（12 点或 21 点，3 分钟或 5 分钟）上每个单元的输出：

每个单元像一个只会答"是"或"否"的问题，+1 和 −1 是它的回答，到输出的权重是这个回答占多少分。单元 6 只在白天短歌答 −0.92，另外三格都答 +1，乘上 −3.54，给白天短歌加 3.26 分，给另外三格各减 3.5 分左右。单元 4 用同样的办法单独压低白天长歌，单元 2 单独压低晚上短歌。单元 5 的两个权重只有 −0.15 和 −0.47，线很平，在整个区域里输出都在 −0.53 到 0.56 之间，乘上 0.25，对总分的影响不到 0.15，几乎没用上。

换一个种子，线会画在别处，准确率在 0.855 到 0.895 之间（种子 1、2、4、5、6）。单元少了就画不好：2→2→1 用种子 1 到 5 训练，准确率只有 0.72 到 0.795；2→4→1（种子 3）是 0.86。

15 个特征的网络做的是同一件事，只是线变成了 15 维空间里的平面，ReLU 单元在平面一侧输出 0、另一侧线性增长；第二层的 8 个单元再把第一层 16 个回答组合一次。

早停

训练时不能看测试集，就用验证集挑轮数：验证集损失最低在第 12 轮（0.4794），最终模型用同一个种子从头训到第 12 轮停下，测试 AUC 0.731；一直训到第 30 轮，测试 AUC 降到 0.692。这叫早停（early stopping）。

验证集只有 400 条、82 个正样本，曲线跳得厉害：第 12、7、6、9 轮的验证损失是 0.4794、0.4872、0.4881、0.4892，差得不多，测试损失其实在第 7 轮最低。换种子也不稳：同一个配方用种子 1 到 11 各训一次，按验证集挑出的轮数从第 2 到第 17 轮都有，测试 AUC 在 0.6948 到 0.7587 之间，中位数 0.7229；训满 30 轮的中位数是 0.7022。11 次里有 9 次早停比训满好。

11初始值：不能全是 0

训练要从一组初始参数出发。逻辑回归可以从全 0 开始（梯度下降那一页就是），网络不行。

全是 0：梯度传不回去

隐藏层输出全是 0，输出层权重的梯度（δ × h）就是 0；输出层权重也是 0，传回隐藏层的误差（w × δ）也是 0，只有输出层的偏置能学。把 3→4→1 小网络从全 0 开始训练 60 轮：所有权重仍是 0，偏置学到 −1.2299，每个样本的预测都是 0.2262，接近训练集的正样本率 0.227。测试 AUC 0.5，什么都没学到。

全都一样：对称

不是 0、但每个单元的初始权重都一样，问题更隐蔽。同一层的单元看同样的输入、有同样的权重，算出同样的输出，分到同样的误差，做同样的更新，永远是彼此的复制品。把二维演示的 2→6→1 网络所有权重都设成 0.5，其余配方不变，训练 300 轮后 6 个单元的权重全是 (−2.82, 3.09)，偏置全是 −1.75：6 个单元画的是同一条线，准确率 0.69，随机初始化时是 0.89。所以初始权重要随机抽，让每个单元从不同的地方出发；偏置一般从 0 开始。

抽多大

抽得太大或太小，数值会一层层放大或缩小。拿 2000 条标准化后的训练样本，送进一个 10 层、每层 16 个 ReLU 单元的网络（权重用种子 5 抽），看每层输出的均方根（平方的平均再开方，代表数值的典型大小；输入是 1）：

第几层标准正态 N(0, 1)He：N(0, 2/输入数)N(0, 0.1²)

标准正态的权重让数值每层放大约 2.8 倍，标准差 0.1 让每层缩到约 0.28 倍。He 初始化按输入个数缩放，方差取 2/输入数，各层基本保持在 1 附近；多乘一个 2，是因为 ReLU 把大约一半的数变成了 0。常见的两种取法：

  • He 初始化：方差 2/输入数，配 ReLU。这一页的网络都用它，二维演示的 tanh 网络也是。
  • Xavier 初始化（也叫 Glorot）：方差 2/(输入数 + 输出数)，不少实现简化成 1/输入数，配 tanh 和 sigmoid。

12梯度消失和 ReLU

误差每往回传一层，都要乘一次激活函数的斜率（第 07 节）。sigmoid 的斜率最大是 0.25（在 z = 0 处），离 0 越远越小。只看斜率这一项，传过 10 层最多剩 0.2510 ≈ 0.00000095。

实际算一下。还是 10 层、每层 16 个单元、同样 2000 条训练样本，sigmoid 和 tanh 用 Xavier（方差取 1/输入数），ReLU 用 He。刚初始化时在全部样本上平均出每层权重的梯度，看它的均方根：

层sigmoid + Xaviertanh + XavierReLU + He
第 1 层9.9×10−90.00670.012
第 5 层1.4×10−50.00640.039
第 10 层0.0120.00680.13
输出层0.150.0210.39

sigmoid 网络第 1 层的梯度不到第 10 层的百万分之一，学习率一样，前面的层几乎不动。两个网络各训练 10 轮（学习率 0.01）：sigmoid 网络第 1 层权重变化的均方根只有 0.0000019，测试 AUC 0.5234，和乱猜差不多；ReLU 网络第 1 层变了 0.15，测试 AUC 0.7359。

这就是梯度消失。ReLU 缓解它的原因很直接：激活的单元斜率正好是 1，误差原样穿过，只乘权重；没激活的斜率是 0，那条路断开，代价是第 05 节的死单元。tanh 在 0 附近斜率是 1，刚初始化时没有消失，但 |z| 一大，斜率同样趋近 0。ReLU 还便宜，一次比较，不用算指数。

更深的网络还靠两样结构：残差连接，每隔几层把输入直接加到输出上，误差多一条不乘斜率的近路；归一化层，把每层的输出拉回均值 0、方差 1 附近。大语言模型里两样都有。

13深度、宽度、批量和 GPU

每层加单元叫加宽，加层叫加深。理论上一个隐藏层只要足够宽，就能逼近任意连续函数，但"足够宽"可能大得不现实。多一层，后一层就能把前一层的回答再组合一次，像第 08 节那样先画线、再拼区域。用几层、每层多宽，和学习率一样，是在验证集上试出来的。

这一页的网络每看一个样本就更新一次（批大小为 1），401 个参数的网络训 30 轮，在一台 Mac 的 CPU 上不到 0.3 秒。大网络一次取一批样本，比如 256 个，前向就成了一次矩阵乘法：

X (256×15) · W1ᵀ (15×16) + b1  ->  Z (256×16)

反向也是矩阵乘法，一批的梯度取平均，更新一次参数。这些乘加互不依赖，GPU 可以同时算成千上万个，所以训练大网络用 GPU。

14在 Android 上运行

预测只用前向。参数少的网络直接手写，第 04 节的 3→4→1 在 Kotlin 里是这样：

import kotlin.math.exp

private val W1 = arrayOf(
    floatArrayOf(2.15f, -0.78f, -1.14f),
    floatArrayOf(0.71f, -0.42f, 1.30f),
    floatArrayOf(-0.59f, -0.99f, -1.25f),
    floatArrayOf(3.21f, 1.30f, 0.39f),
)
private val B1 = floatArrayOf(0.05f, -0.34f, 0f, 0.01f)
private val W2 = floatArrayOf(0.33f, 0.59f, 1.38f, 0.89f)
private const val B2 = -1.81f

// x = [偏好 ÷ 30, 热度, 关注]
fun predict(x: FloatArray): Float {
    var z = B2
    for (j in 0 until 4) {
        var zj = B1[j]
        for (k in 0 until 3) zj += W1[j][k] * x[k]
        z += W2[j] * maxOf(zj, 0f)      // ReLU
    }
    return 1f / (1f + exp(-z))          // sigmoid
}

// predict(floatArrayOf(6 / 30f, 0.32f, 0f)) 约等于 0.3136

15→16→8→1 也是这样几重循环，前面多一步：输入先按训练集的均值和标准差标准化。比如偏好这一项是 (affinity ÷ 30 − 0.0898) ÷ 0.104，样本 2462 标准化后约是 1.06。这 30 个常数是模型的一部分，要和权重一起带上；手机上漏了这一步，或者用了另一份均值，概率就全错了，而且不会报错。

模型大了、结构复杂了，就不再手写，而是导出成模型文件，在手机上用推理运行时加载：

做法是什么适合

15常见坑

现象原因处理
训练集指标一直涨，验证集先涨后跌过拟合：参数多、数据少，开始记训练集里的噪声。训练 AUC 超过真实概率能做到的，就是在记噪声按验证集早停；L2、dropout；加数据；缩小网络
某个隐藏单元的输出永远是 0死掉的 ReLU：输入全为正而权重全为负；或者学习率太大，把偏置推得很负输入标准化；Leaky ReLU；调小学习率；统计每个单元的激活比例
所有样本的预测都一样；或者一层里几个单元的权重一模一样权重全 0 初始化，梯度传不回去；或者初始值全相同，对称性没打破随机初始化（He 或 Xavier）
损失变成 NaN，或者突然暴涨学习率太大；初始值太大，数值逐层放大；p 算成了 0 或 1，取了 ln 0调小学习率；He 或 Xavier 初始化；算损失前把 p 限制在 [10−12, 1 − 10−12]
深层网络前面几层几乎不动梯度消失：sigmoid 的斜率最多 0.25，层层相乘隐藏层用 ReLU；合适的初始化；残差连接、归一化层
换个随机种子，测试 AUC 差了 0.06小数据上训练本身不稳：种子 1 到 11 早停后的测试 AUC 从 0.6948 到 0.7587多跑几个种子看分布，或者把几个模型的预测平均；报结果时写清种子
测试 AUC 高了 0.02，上线后没区别600 条测试样本，AUC 本身就有约 0.025 的抽样误差用自助法看区间，或者换更大的测试集
训练久了，预测的概率整体偏高过拟合也让概率失准：第 30 轮测试集的平均预测 0.2609，实际正样本率 0.2367；第 12 轮是 0.2296早停；上线前对比平均预测和实际比例，见评估
手机上算的概率和服务端对不上特征算法不一致：没做标准化、均值和标准差不是训练时那份、特征顺序错了标准化常数和权重一起导出；拿同一批样本两边各算一遍，逐个对数

数字都来自一个固定种子的 Node.js 脚本（纯 JavaScript，没用机器学习库）和它生成的 3000 条示意曝光，训练都是逐样本的随机梯度下降。3→4→1：特征 [affinity/30, heat, follow]，He 初始化种子 7，学习率 0.05，60 轮，权重取两位小数；前向、反向和学一步（学习率 0.05）按两位小数的权重手算后用脚本核对，数值梯度的扰动是 10−6。15→16→8→1：特征按训练集标准化，种子 11，学习率 0.01，30 轮，按验证集损失取第 12 轮；种子波动换的是种子 1 到 11。二维演示：坐标缩放到 [−1, 1]，2→6→1 tanh，种子 3，学习率 0.05，300 轮；全 0.5 初始化、2→2→1、2→4→1 只改了这一处。初始化和梯度消失：10 层、每层 16 个单元，种子 5，输入是标准化后的 2000 条训练样本，训练对照为学习率 0.01、10 轮。AUC 误差：自助法 2000 次，种子 99。10 倍数据：同一生成器接着生成第 31 到 210 天的 18000 条。Kotlin 代码按 float32 核对过结果；推理运行时一段按公开文档写，没有在真机上跑。
